
# Healthcare Analytics Using SQL

## Project Overview
This project focuses on analyzing healthcare data using PostgreSQL to understand patient appointments, doctor performance, treatment costs, and billing activities. The goal is to extract meaningful insights from healthcare data using SQL queries.

## Database Tables
The project consists of five tables:

- **Patients:** Contains patient details, demographics, registration dates, and insurance information.
- **Doctors:** Contains doctor details, specializations, years of experience, and hospital branches.
- **Appointments:** Stores appointment dates, times, reasons for visits, and appointment statuses.
- **Treatments:** Contains treatment types, descriptions, treatment dates, and costs.
- **Billing:** Stores billing amounts, bill dates, payment methods, and payment statuses.

## Tools Used
- PostgreSQL
- pgAdmin 4
- SQL

## SQL Concepts Covered
- Data retrieval and filtering using `SELECT` and `WHERE`
- Aggregate functions such as `COUNT()`, `SUM()`, `AVG()`, `MIN()`, and `MAX()`
- Data grouping and sorting using `GROUP BY` and `ORDER BY`
- Filtering grouped data using `HAVING`
- Joining multiple tables using `JOIN`
- Subqueries and Common Table Expressions (CTEs)
- Window functions such as `RANK()` and `ROW_NUMBER()`
- Conditional logic using `CASE`
- Date-based analysis using PostgreSQL date functions

## Key Business Questions
- How many patients, doctors, appointments, and treatments are recorded?
- Which doctors handle the highest number of appointments?
- What are the most common treatment types and appointment reasons?
- What is the average cost of treatments?
- Which doctors generate the highest billed revenue?
- What are the appointment cancellation and completion rates?
- Which payment methods are used most frequently?
- How do appointment volumes and billing amounts vary over time?

## Project Objectives
- Analyze healthcare operations and appointment patterns.
- Evaluate doctor workload and performance.
- Understand treatment costs and billing trends.
- Calculate key performance indicators (KPIs).
- Strengthen practical SQL skills through real-world analytical questions.

## Key Learnings
This project helped me practice SQL querying, data aggregation, multi-table joins, subqueries, CTEs, window functions, and KPI calculations to analyze structured healthcare data.

## Conclusion
The project demonstrates how SQL can be used to explore healthcare operations and generate insights that support data-driven decision-making.
